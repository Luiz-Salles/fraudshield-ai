# FraudShield AI

Sistema Inteligente de Detecção de Fraudes Financeiras utilizando Machine Learning.

## Tecnologias

- Python
- Pandas
- Scikit-Learn
- Streamlit
- Isolation Forest

## Funcionalidades

- Detecção automática de anomalias
- Análise de transações financeiras
- Dashboard interativo
- Score de risco

## Como executar

```bash
pip install -r requirements.txt

python generate_data.py

python detector.py

streamlit run app.py
```
